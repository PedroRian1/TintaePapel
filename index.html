III. Sobre o Curador

Sou estudante de Ciência da Computação e desenvolvedor web. Gosto de construir coisas na internet, mas gosto igualmente do cheiro de livro velho. Este site nasceu dessa mistura: um projeto de portfólio feito só com HTML, CSS e JavaScript, sem frameworks, para mostrar o que dá para fazer com o básico bem feito.

Aqui você encontra um catálogo filtrável, tipografia de época e um layout responsivo. O código está aberto no GitHub, e fica a sugestão de leitura para quem quiser fuçar por dentro.

  • HTML5 semântico
  • CSS3 (variáveis, grid, flexbox)
  • JavaScript puro
  • GitHub Pages
